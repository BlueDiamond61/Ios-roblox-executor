# Local Luau Payload Library

This folder contains example source files for the MobileBlox Studio local editor.

Files are treated as text documents. The app can import, edit, organize, and export them locally. It does not inject code into Roblox, attach to another process, or execute payloads inside the Roblox client.

Target version metadata for this project is recorded separately in `MobileBloxStudio/Offsets.h` and `MobileBloxStudio/VersionInfo.h`. Those headers contain version labels and compatibility checks only; they do not contain memory offsets.
